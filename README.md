# 联铺 Windows 客户端

Windows x64 数字资料经营管理软件。**源码可见、商业授权，不属于标准开源项目。** 官方安装包需要发行方提供的兑换码；下载完整源码并不获得经营使用授权。详见 [许可](LICENSE)。

## 下载使用

从本仓库 Releases 下载最新 MSI，安装后从桌面“联铺”启动。首次激活自动识别设备；支持 7 天、30 天、365 天和永久授权。核销成功、最终授权验签并保存后才开放完整功能。正常重装软件保留授权；重装 Windows 或清除 TPM 需要联系发行方。

到期保留只读查看、导出与备份。续期不会自动重启托管。经营账号登录和软件授权是不同流程。当前版本是未取得 Windows 商业发布者签名的开发验证版。

安装新版会自动替换旧版程序，保留本机成员、经营资料、闲鱼会话文件和设备授权，沿用原桌面图标。无需先卸载旧版。平台已经过期的会话仍需要重新扫码。[升级保留规则](docs/upgrade-retention.md)

## 功能与边界

0.5.4 新增加密运行诊断与主动反馈：全局、设置、错误及激活页面可提交问题，支持草稿、脱敏预览和可选遮挡截图。激活后默认开启脱敏错误回传，管理员可以关闭且升级保留选择；回传和 GitHub 转交分别显示真实状态。[反馈使用说明](docs/feedback-0.5.4.md)

包含工作台、账号、商品、资料库、逐条库存、订单交付、消息客服、规则、客户备注、售后、统计、成员权限、设置和数据备份入口。付款核验、重复交付防护和未知结果待核验保留。完整项目需求入口及真实能力边界见 [需求状态](docs/requirements-status.json)。尚未取得真实平台验证的操作继续明确阻断，不能将本地测试当作真实经营接入成功。

0.5.3 修复重启后将已保存会话误判为需要登录的问题。在“经营账号 → 账号详情”点击“检查并同步（不会发送）”，即可恢复本人会话并逐项读取商品、消息和可核验订单；扫码绑定后也会自动执行这组只读检查。托管仍需明确开启。功能状态区提供逐项重试及具体说明，未接入的发布、退款等操作单独列明。[账号检查与验证记录](docs/validation-0.5.3.md)

## 从源码构建

开发者使用 Windows x64、Node.js 24、npm，以及系统 .NET Framework 4.x 编译器和 Windows Installer。客户安装包已包含 Electron，无需终端用户部署环境。

```powershell
npm ci
npm run build:native
npm test
npm start
npm run package
```

MSI 在 release 中生成。默认构建不需要发行私钥，也不签发更新清单；客户激活流程仍需真实兑换码。只有发行方在本机保护目录已有匹配更新密钥时，才可使用打包脚本的 --sign-update 选项。客户仓库不包含任何发行密钥。
