# 本轮改动

客户 0.5.3：修复已保存闲鱼会话重启后被误判需要登录、只读同步无法恢复会话、商品末页字符串标记被误判继续分页，以及消息连接初始化时过早报告断开的问题。保留每账号独立队列和成员范围检查，不通过检查按钮开启托管或发送消息。

账号详情改为四项日常功能及五组尚未接入的平台操作，提供逐项读取、部分内容提示及具体下一步；扫码绑定后自动只读检查。去除重复状态行和短表分页，检查登录时显示进度，修复本地界面缓存导致升级后仍显示旧界面的问题。只清理界面缓存，不清除账号会话和用户资料。

业务实现根据本项目需求和现场只读证据独立完成。本轮仅参考公开 README 中“添加账号—检查—配置规则—开启”的功能流程，未以竞品源码为改写底稿，未增加第三方依赖。具体验证与未完成范围见 validation-0.5.3.md。

发行检查：运行时产生的诊断日志不再进入载荷和随包清单；重新生成 Chromium 许可摘录后恢复其原始换行字节，使原文与既有 SHA-256 记录一致，许可内容未改变。

客户 0.5.2：建立源码可见发行边界，保留完整客户逻辑、公开验签配置及设备激活检查；构建默认不依赖更新签发密钥。

升级安装：新版文件成功写入后才移除旧版产品；固定组件标识、拒绝降级、完整替换同版本程序资源，保留用户数据与原授权。安装器不管理用户存储或 TPM 密钥。故障注入发现本机 Windows Installer 回滚权限不足，记录为未通过；正常升级及资料保留单独验证。

管理器 1.1.0：本地浏览器界面、一次性启动链接、托盘和单实例；兼容既有加密账本和文件导入导出；新增真实连接检查，凭据变化后清除过期检查状态。

原内部开发历史保留在发行方归档。当前 Git 历史从本次干净导出起始。测试结果与安装后、云端验证分开记录。
