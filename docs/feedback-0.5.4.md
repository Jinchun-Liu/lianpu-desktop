# 联铺 0.5.4：运行诊断与用户反馈

本版本为开发验证版本。反馈与经营、激活、成员登录相互独立；未激活和授权到期也可以主动反馈。诊断功能不会开启闲鱼托管。

## 如何使用

在全局“反馈与诊断”、设置中的同名入口或错误提示中打开反馈。填写发生问题的功能、问题描述、操作步骤、预期和实际结果，可选联系方式。先预览附带诊断，再提交；可以保存加密草稿，稍后继续。

软件激活后默认开启脱敏错误自动回传，并展示说明。本机管理员可以关闭，升级、续期和重新打开不会重置该选择。关闭后，尚未发出的自动报告保留本机，不继续发送；已经提交的请求无法撤回。主动反馈不受此开关限制。

截图仅由用户选择，最多两张，选择原图上限 5 MiB，尺寸受限并重新编码；提交前可拖动或使用坐标输入遮挡敏感区域，再预览、确认或删除。每张处理后必须小于等于 256 KiB，超过时会提示，不会静默丢弃。遮挡后仍应人工检查整张图片。

## 状态含义

| 状态 | 含义和下一步 |
| --- | --- |
| 草稿 | 只在本机，尚未提交 |
| 待提交 | 尚未获得完整云端回执；保留原编号重试 |
| 文字已收到，截图未完成 | 文字已保存；可以继续原报告补传截图 |
| 已收到 | 云端已持久保存，不等于开发者已处理 |
| GitHub 待同步 / 结果待核对 | 云端正在转交或核对，不重新创建反馈 |
| 尚未接通或暂不可用 | 按错误编号检查网络或联系发行方；不会用固定提示冒充收件成功 |

关闭网页不会取消管理器已提交的任务。关闭客户程序会保留未完成反馈，重新打开后按原编号恢复。云端额度不足会暂停；有效的离线经营授权不受反馈故障影响。

## 记录与隐私

自动诊断只记录版本、构建编号、系统版本、功能/阶段、耗时、结果、相对错误位置和最近最多 30 步。有关账号连接、规则资料绑定及库存的上下文只返回经过成员权限核对的状态；不会附带完整业务对象、聊天正文、买家身份、链接、提取码、Cookie、兑换码或密钥。异常错误正文不直接进入自动报告。

普通本机轨迹加密保存，最多 7 天、20 MiB；反馈记录最多 100 份，本机诊断目录容量保护为 50 MiB。不会为腾空间删除未提交报告，可以导出后清理已完整收件记录。加密依赖 Windows 当前用户保护；系统保护不可用时拒绝以明文降级保存。

反馈文字进入发行方私有 GitHub Issues，截图保存在受限授权服务，只有发行方管理器可查看。云端已同步正文保留 30 天、截图 14 天；未同步正文保留至可转交或容量满。GitHub Issue 的保留由发行方在 GitHub 管理，不等同于云端正文 30 天期限。不要在主动反馈文字和截图中填写不必要的秘密。

突然断电仅记录“上次未正常退出”，不代表捕获到了具体崩溃原因。自动脱敏无法判断用户主动选择图片里所有业务内容，图片必须人工检查。

## 独立开发与当前边界

新增报告协议、加密记录服务、权限化业务状态提取、反馈表单、截图处理和诊断入口；沿用现有 UI 组件体系、Electron 和第三方许可，本次没有新增运行依赖。服务端故障不改变库存、订单或交付结果；未知交付仍须原有核验流程。

验证记录见 validation-0.5.4.md。源码可见商业许可与既有用户授权权益保持不变；新增安全审计在独立任务进行，未合入前不能声称本版本已具备该任务全部防护。
