# 安装新版并保留原来的使用状态

需求修订：2026-09-12。客户版从 0.5.2 起采用先安装新版、后移除旧版的 Windows Installer 升级事务。

## 用户操作

保存正在编辑的内容并从托盘退出联铺，然后双击发行方提供的新版 MSI。安装结束后继续使用原来的“联铺”桌面图标。在同一 Windows 用户下，新版自动使用原来的本机成员、经营资料、闲鱼会话和设备授权，无需重新导入、重新购买授权或重复添加账号。

设置中的“版本与升级”仍提供签名清单核验、安装包核验及安装并退出。也可以直接安装新版 MSI，不必先卸载旧版。安装后同一产品系列只保留一个已安装版本，旧版专用程序文件及登记由安装事务移除；拒绝使用更低版本覆盖。

## 数据保留约定

- 产品标识和当前用户的安装位置保持一致；每次发布使用新的 ProductCode，同一系列固定 UpgradeCode。
- 本机成员、加密资料、记住的登录和闲鱼独立会话继续使用 `%APPDATA%\Lianpu`，不以版本号分目录。
- 设备授权继续使用原有 TPM 密钥与 `%PROGRAMDATA%\Lianpu\Licensing\v1`；升级、正常卸载均不删除或重新生成这些材料。
- 安装表只管理应用程序和快捷方式，不包含业务存储、浏览器会话、TPM 密钥或授权记录。
- 安装文件完整写入之后才移除旧版；这两步位于同一 Windows Installer 事务中，任何必需文件缺失均不能忽略为成功。使用稳定组件标识，避免旧版卸载误删新版共同文件。
- 版本资源使用文件实际版本；无版本号的应用资源跟随主程序升级，避免旧的界面和业务归档滞留。

闲鱼平台本身过期、主动退出、撤销或要求验证的会话仍需要重新扫码。更换 Windows 用户、重装系统、清除 TPM 或丢失设备密钥不属于普通软件升级；不能承诺这些情况自动继承授权。续期和升级不会擅自恢复已暂停的托管。

## 实现依据与验证边界

事务顺序为 `InstallExecute → RemoveExistingProducts → InstallFinalize`，依据 [Microsoft Windows Installer 文档](https://learn.microsoft.com/en-us/windows/win32/msi/removeexistingproducts-action)。文件版本及必需标记依据 [File 表文档](https://learn.microsoft.com/en-us/windows/win32/msi/file-table)。

测试与发布报告分别记录：安装表约定检查、隔离升级与回滚、真实客户安装和数据校验。源码与安装表检查不代替真实账号在线验证。安全软件、系统磁盘和 Windows Installer 自身发生错误时应停止并保留日志，不关闭防护或删除用户资料。
